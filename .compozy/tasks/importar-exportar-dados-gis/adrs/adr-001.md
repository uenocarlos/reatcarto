# ADR-001: Import/Export Scope — Map or Selection per Operation

## Status

Accepted

## Date

2026-08-10

## Context

ReatCarto organizes geospatial data as elements within owned maps (up to 5,000 elements per map). Users need to interchange data with external GIS tools (QGIS, ArcGIS, etc.) via GeoJSON and Shapefile. The scope of each operation — whole map versus a subset of elements — affects UI flows, file size, and offline behavior.

## Decision

Every import and export operation presents a scope choice: **whole map** or **selected elements**. When the user chooses selection-based export but no elements are selected, the operation is blocked with guidance to select elements on the map first. Import always targets the currently open map; scope on import refers to whether the operation affects all existing elements (replace mode) or only adds new ones (merge mode — see ADR-002).

## Alternatives Considered

### Alternative 1: Whole map only

- **Description**: Always export/import the entire map contents.
- **Pros**: Simplest UX and implementation.
- **Cons**: Cannot share or ingest partial datasets; forces users to create temporary maps for subsets.
- **Why rejected**: User confirmed need for both scopes.

### Alternative 2: Selection only

- **Description**: Users must always select elements before export; import always merges.
- **Pros**: Precise control.
- **Cons**: Friction for the common case of full-map interchange.
- **Why rejected**: User confirmed need for both scopes.

### Alternative 3: Map or selection with silent fallback

- **Description**: If no selection exists, export the whole map automatically.
- **Pros**: Fewer clicks.
- **Cons**: Risk of accidental full-map export when the user intended a subset.
- **Why rejected**: User chose explicit blocking when selection mode is chosen without a selection.

## Consequences

### Positive

- Supports both full-map interchange and targeted data sharing.
- Prevents accidental full-map export when selection was intended.

### Negative

- Every operation requires an extra scope decision step.

### Risks

- Users may not discover selection mode; mitigated by clear dialog labels and blocking message when selection is empty.

## Implementation Notes

- Selection state must be readable from the map editor at export time.
- Replace-mode import (ADR-002) deletes all map elements before import regardless of export scope semantics.
