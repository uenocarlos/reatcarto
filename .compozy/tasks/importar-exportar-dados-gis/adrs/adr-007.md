# ADR-007: UI Placement — Map Editor Toolbar Actions

## Status

Accepted

## Date

2026-08-10

## Context

Import and export of GIS data are actions performed in the context of editing a specific map. The map editor already exposes cartographic export (PDF/PNG) and memorial generation from its toolbar.

## Decision

Add **"Import data"** and **"Export data"** actions to the map editor toolbar, alongside existing export actions. Each opens a modal dialog guiding the user through scope, format, strategy (import only), mapping review (import only), and confirmation steps. No separate sidebar panel is introduced in this feature.

## Alternatives Considered

### Alternative 1: Dedicated sidebar panel

- **Description**: Persistent import/export panel with history and advanced options.
- **Pros**: Room for batch operations and history.
- **Cons**: Adds UI complexity; import/export are infrequent operations.
- **Why rejected**: User chose toolbar integration.

### Alternative 2: Toolbar + sidebar

- **Description**: Quick actions in toolbar, details in sidebar.
- **Pros**: Progressive disclosure.
- **Cons**: Two entry points to maintain.
- **Why rejected**: User chose toolbar only.

## Consequences

### Positive

- Consistent with existing export entry points.
- Keeps map canvas area uncluttered.

### Negative

- Modal dialogs may feel constrained for complex mapping review on small screens.

### Risks

- Mobile usability of mapping review table; mitigated by responsive layout in TechSpec.

## Implementation Notes

- Buttons visible only to the map owner in the editor context.
- Disabled state with tooltip when user lacks permission (should not occur for owners).
