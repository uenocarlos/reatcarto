# ADR-004: Canvas Limits, Empty Confirm, and Priority Tiers

## Status

Accepted

## Date

2026-08-12

## Context

Drawn icons must stay sharp enough for map/legend/export without bloating per-user storage. Empty confirms would pollute the library. Scope must stay ordered so library + single-object drawing ships before advanced editor affordances.

## Decision

### Limits

- Fixed canvas **256×256** px.
- Export **PNG with transparent background**.
- Maximum about **200 KB** per exported icon; over-limit confirm is rejected with a clear message.

### Confirm / cancel

- Confirm with an empty canvas (no drawable content) is **blocked**; user is told to draw something.
- Cancel / close without confirm discards the draft; point style and library unchanged.

### Priority tiers

**P0**

- Open editor (desktop), draw with pencil, rectangle, circle, line, color, stroke width.
- Select, move, resize, rotate a **single** object.
- Export PNG, save to library + apply to point; show colored icon on map/legend/export.
- Library in StylePanel: apply, remove, optional name.

**P1**

- Multi-select with group move/resize/rotate.
- Undo / redo.
- Eraser and clear canvas.

**P2**

- Triangle shape and UX polish.

## Alternatives Considered

### Alternative 1: 512×512 and ~500 KB

- **Description**: Larger canvas for print fidelity.
- **Pros**: Higher detail.
- **Cons**: Heavier library; markers on map are ~14–32 px.
- **Why rejected**: User chose 256 / ~200 KB for MVP.

### Alternative 2: Allow empty PNG save

- **Description**: Transparent empty asset enters library.
- **Pros**: No validation edge.
- **Cons**: Library spam; broken-looking markers.
- **Why rejected**: User chose block empty confirm.

### Alternative 3: Undo/multi-select in P0

- **Description**: Richer editor before library reuse.
- **Pros**: Safer drawing UX immediately.
- **Cons**: Delays the reuse value of the library.
- **Why rejected**: User confirmed library + single-object P0; advanced tools P1.

## Consequences

### Positive

- Predictable asset size and clear acceptance bars.
- First ship delivers create + reuse.

### Negative

- Power users wait for undo/multi-select.
- Very detailed artwork may need simplification to fit 200 KB / 256 px.

### Risks

- Dense drawings exceeding 200 KB — mitigate with in-editor feedback before confirm when possible.

## Implementation Notes

Exact compression strategy is TechSpec. Product requires transparent PNG, dimension and size caps, and the P0/P1/P2 split above.
