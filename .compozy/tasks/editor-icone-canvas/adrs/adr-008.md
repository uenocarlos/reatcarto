# ADR-008: Icon GET ACL and Public Icon Endpoint

## Status

Accepted

## Date

2026-08-12

## Context

Library icons are private catalog entries, but markers on shared/public maps must still load. Photos already split authenticated get vs `public/photo.php` gated on public eligibility.

## Decision

### Authenticated `GET /php/icons/get.php?id=`

Allow when:

1. Requester is the icon owner, or
2. Requester is authenticated and can read at least one `map_elements` row whose `style->>'custom_icon_url'` references this icon id (same map-access rules used to load that element).

Deny otherwise (403/404 consistent with photos).

### Public `GET /php/public/icon.php?id=`

Allow only when at least one **publicly visible** element on a **public-eligible** map references this icon in `custom_icon_url`. Soft-hidden library membership does not affect this.

### Library mutations

`list` / `upload` / `remove` (soft-hide): owner only via `require_active_user`.

## Alternatives Considered

### Alternative 1: Any authenticated user with UUID

- **Pros**: Simple.
- **Cons**: UUID leakage shares all icons across tenants.
- **Why rejected**: User chose stricter ACL.

### Alternative 2: All icon GETs public

- **Pros**: Trivial markers.
- **Cons**: Library enumerable/leak risk if IDs leak.
- **Why rejected**: User chose conditional public endpoint.

## Consequences

### Positive

- Collaboration and public maps keep working.
- Catalog list stays private to the owner.

### Negative

- Reference lookup query on GET (index `custom_icon_url` / expression recommended).
- Soft-hidden icons may remain publicly fetchable while still on a public map — intended.

### Risks

- Slow GET under load — mitigate with indexed JSON path or stored `icon_id` later; MVP may use `style->>'custom_icon_url' LIKE '%id=%'` / equality on full URL.

## Implementation Notes

When creating an icon, return both `id` and `url` (`/php/icons/get.php?id=`). Client writes that `url` into `custom_icon_url`. Public map serializers rewrite matching URLs to `/php/public/icon.php?id=` when emitting public element payloads (parallel to photo URL rewriting if present).
