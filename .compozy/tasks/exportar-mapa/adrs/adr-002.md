# ADR-002: Owner-Only Export from the Map Editor

## Status

Accepted

## Date

2026-08-03

## Context

The login-and-PostGIS product rules already state that anonymous public visitors must not export PDF or download geographic products. Export consumes the full private map content (all owner-visible elements, styling, and layout). Entry points outside the authenticated owner editor would either leak private cartography or re-load a full map solely for print.

## Decision

Map export is available **only** to the authenticated map **owner**, **only** inside the **map editor** for that map. No export on public map view, gallery, or dashboard list for this version. Opening export reads the current editor session state (viewport, layer visibility, basemap) and applies print configuration in the export session without requiring a separate dashboard flow.

## Alternatives Considered

### Alternative 1: Export on public maps for published work

- **Description**: Allow anonymous download from public view.
- **Pros**: Broader sharing of finished layouts.
- **Cons**: Conflicts with login-and-PostGIS non-goals; complicates watermarking and load.
- **Why rejected**: Prior product decision and user chose editor-only.

### Alternative 2: Dashboard shortcut that loads the map then export

- **Description**: Export entry from map list without opening the full editor UX.
- **Pros**: Fewer clicks for power users.
- **Cons**: Duplicate state loading, extra path to maintain.
- **Why rejected**: User chose editor-only as the single entry.

## Consequences

### Positive

- Clear permission boundary: export capability equals owner edit access.
- Single integration surface for UX and stories.

### Negative

- Visitors and collaborators (if added later) cannot export until a future decision expands access.

### Risks

- Users may expect export after publishing publicly → communicate that export remains owner-side; public remains view-only.

## Implementation Notes

Align with existing owner checks used for map editing. Public routes must not expose the export control.
