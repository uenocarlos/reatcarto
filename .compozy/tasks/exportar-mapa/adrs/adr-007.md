# ADR-007: Dedicated Leaflet Instances for Export Composition

## Status

Accepted

## Date

2026-08-03

## Context

Export needs cartographic chrome (graticule, scale, north arrow), layout regions (title, legend, insets, institutional footer), and temporary layer/basemap toggles. Reusing the editor Leaflet instance would mutate live editor state and risk leaking export-only UI into the owner’s drafting surface when canceled.

## Decision

Host **dedicated Leaflet map instance(s)** inside the export shell:

1. **Main export map** — separate `react-leaflet` `MapContainer` mounted only while export is open.
2. **Inset maps (0–2)** — additional Leaflet instances when location insets are enabled.
3. On open: seed center, zoom, visible element set, and basemap from a snapshot of the editor (ADR-006).
4. On cancel/close: unmount export maps and discard session state; the editor instance is never required to restore export-only mutation.

## Alternatives Considered

### Alternative 1: Reuse editor Leaflet instance

- **Description**: Apply export chrome and toggles on the live editor map; restore on close.
- **Pros**: Less memory; single tile cache.
- **Cons**: Fragile restore paths; chrome leakage; hard cancel isolation.
- **Why rejected**: User required editor isolation on cancel.

### Alternative 2: One-shot static capture of editor viewport

- **Description**: Capture editor once as an image; layout around a fixed bitmap only.
- **Pros**: Simple.
- **Cons**: No live pan/zoom of export session; basemap/layer toggles force re-capture and weaken WYSIWYG insets.
- **Why rejected**: User chose live separate maps.

## Consequences

### Positive

- Editor remains authoritative after cancel (ADR-003, ADR-006).
- Export chrome can be implementation-specific without polluting `MapEditor` UX.

### Negative

- Double tile loads while export is open (editor behind modal still mounted).
- Higher memory when two (or three) maps display simultaneously.

### Risks

- Modal teardown must fully destroy Leaflet instances to avoid “map container is already initialized” and zombie tile requests. Unmount on shell close is mandatory.

## Implementation Notes

`MapEditor` remains the sole entry; export shell is a full-surface `Dialog`/`Sheet` over the editor. Lift editor basemap into controlled state (or read via snapshot getter) so inheritance matches ADR-006 — basemap today defaults to internal state in `LeafletMap`.
