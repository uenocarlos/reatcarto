# ADR-003: Ephemeral Export Session Configuration

## Status

Accepted

## Date

2026-08-03

## Context

Full-parity export has many options (paper, legend, insets, colors, DPI). Persisting them requires server models or client storage and reintroduction UX. The printJs baseline treats the export window as a configuration session ending in a download.

## Decision

Export preferences live **only for the open export session**. Closing the export UI discards configuration. Reopening starts from defaults (title from map name; empty authorship fields; quality defaults from printJs; map state inherited from the **current** editor state). No server-side print layout entity and no localStorage print preference packing for this version.

## Alternatives Considered

### Alternative 1: Per-map server-saved print layouts

- **Description**: Store last paper/legend/location config with the map.
- **Pros**: Repeatable institutional templates.
- **Cons**: New domain model, conflict with “ephemeral print” expectation, more scope before first export works.
- **Why rejected**: User chose session-only.

### Alternative 2: Browser localStorage per map

- **Description**: Remember options on device without server.
- **Pros**: Convenience without backend.
- **Cons**: Device-bound, surprise configs, privacy/storage cleanup issues.
- **Why rejected**: User chose session-only.

## Consequences

### Positive

- No template schema or migration; PRD remains focused on compose-and-export.
- Behavior matches “open, tune, export, done.”

### Negative

- Users reconfigure complex inset layouts each time.

### Risks

- Frustration on repeated municipality setup → mitigate with good defaults (editor state inheritance, sensible paper/DPI) and clear preview.

## Implementation Notes

Cancel or close must not persist options and must not leave the main editor’s layer/basemap state permanently changed to export-only choices unless product later decides shareback; baseline is editor state restored / untouched after cancel (export adjustments apply within the export surface only).
