# ADR-003: Owner-Only PNG Export from the Map Editor

## Status

Accepted

## Date

2026-08-02

## Context

The existing export modal can produce PNG and PDF, but it is not reachable from the UI. The prior account PRD already forbids anonymous PDF export and geographic download from the public gallery. This initiative asks specifically for PNG composition export.

## Decision

- Export is available only to the authenticated map owner inside the map editor.
- Output format for this PRD is PNG only; PDF export is out of scope.
- Anonymous gallery visitors and non-owners cannot open the export composition screen or obtain the PNG through this feature.
- On native Capacitor builds, successful export may use the platform share sheet after generating the PNG; on web, the browser downloads the file.

## Alternatives Considered

### Alternative 1: Keep PDF alongside PNG

- **Description**: Same composition options for PNG and PDF.
- **Pros**: Reuses existing jsPDF path.
- **Cons**: Extra validation and layout edge cases; user asked for PNG only.
- **Why rejected**: Explicit Non-Goal for this PRD.

### Alternative 2: Allow public PNG export

- **Description**: Visitors can export published maps.
- **Pros**: Easier sharing of public work.
- **Cons**: Conflicts with the publication PRD’s export restrictions and ownership model.
- **Why rejected**: User limited access to the owner in the editor.

## Consequences

### Positive

- Clear permission boundary aligned with private map ownership.
- Focused delivery on one lossless raster format suitable for documents and mobile viewing.

### Negative

- Users who only have a public link cannot produce a branded PNG without ownership access.

### Risks

- Owners may expect PDF later; document it under Non-Goals so scope stays clear.

## Implementation Notes

Surface a discoverable export entry point in the map editor. Close or leave the modal after success consistently with existing toast feedback patterns.
