# APK Android

Coloque o arquivo gerado pelo Gradle neste diretório com o nome `ReatCarto.apk`.

O endpoint público `/php/download-apk.php` envia esse arquivo. A tela de login exibe o QR code e o link de download.

Não versione o `.apk` (é grande). Copie-o para o servidor em `/var/www/novoreatcarto/apk/ReatCarto.apk`.
